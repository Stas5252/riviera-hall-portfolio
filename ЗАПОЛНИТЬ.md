# Что нужно заполнить перед запуском

Обновлено 11 августа 2026.

**Дизайн сайта не менялся.** Отзывы, заголовки, шрифты, вёрстка, тексты — всё как было.
Правились только вещи, которых не видно: битые ссылки, зарубежные CDN, пути к файлам,
конфигурация хостинга.

---

## 1. Приём заявок — главное

В [index.html](index.html) у формы пустой атрибут:

```html
<form class="booking-form" id="form" data-endpoint="" novalidate>
```

Нужно поднять обработчик на хостинге и вписать адрес:

```html
<form class="booking-form" id="form" data-endpoint="/api/lead" novalidate>
```

Форма отправляет POST с JSON:

```json
{
  "name": "Ирина",
  "tel": "+7 900 123-45-67",
  "company": "",
  "page": "https://riviera-hall.ru/",
  "ts": "2026-08-11T14:22:31.000Z"
}
```

- `company` — ловушка для ботов, живой человек её не видит.
  **На стороне обработчика: если `company` не пустое — молча выбросить заявку.**
- `ts` — время отправки в UTC.

Пока атрибут пустой, форма не обманывает: пишет «Заявка не отправилась» и показывает
телефон. **Обязательно отправьте тестовую заявку с реального телефона и убедитесь,
что она дошла.** Форма, молча теряющая заявки, — самая дорогая ошибка при запуске рекламы.

## 2. Телефон — 6 мест

В `href` — только цифры (`+7XXXXXXXXXX`), в тексте — как угодно.

| Файл | Где |
|---|---|
| index.html | бургер-меню, `.drawer__tel` — href и текст |
| index.html | блок заявки, `.booking-contacts b` — текст |
| index.html | JSON-LD, поле `telephone` |
| privacy.html | реквизиты оператора, п. 1 |
| consent.html · terms.html · offer.html | реквизиты (если оставите эти документы) |

```bash
grep -rl "70000000000\|+7 (000) 000-00-00" --include="*.html" . | xargs sed -i 's|+70000000000|+79001234567|g; s|+7 (000) 000-00-00|+7 (900) 123-45-67|g'
```

## 3. Адрес, город, координаты

| Что | Где |
|---|---|
| Точный адрес | index.html, блок «09 — как проехать» (сейчас `наб. —————, д. —`) |
| Город, улица, дом, индекс | index.html, JSON-LD `address` (сейчас `УКАЖИТЕ ГОРОД`) |
| Координаты | index.html, iframe карты **и** JSON-LD `geo` |

Координаты: Яндекс.Карты → правый клик по точке → «Что здесь?» → скопировать два числа.

```html
<!-- в ссылке карты порядок ДОЛГОТА,ШИРОТА -->
<iframe src="https://yandex.ru/map-widget/v1/?ll=ДОЛГОТА%2CШИРОТА&z=16" …>

<!-- в JSON-LD порядок обычный -->
"geo": { "@type": "GeoCoordinates", "latitude": ШИРОТА, "longitude": ДОЛГОТА }
```

Сейчас карта показывает Красную площадь, а `geo` — нули, то есть точку в Атлантике.
Разметка с нулевыми координатами хуже, чем её отсутствие: Яндекс её отбракует.

**Отдельно про город.** Его нет ни в `title`, ни в `description`, ни в `h1`. Запросы вида
«шатёр для свадьбы в \<город\>» — основной поисковый спрос для площадки, и без топонима
сайт по ним не покажется. Я это **не трогал**, потому что заголовок виден на странице —
решайте сами, добавлять ли.

## 5. Метрика

В [js/consent.js](js/consent.js), строка 10:

```js
const METRIKA_ID = '';        // ← номер счётчика
```

Пока пусто, счётчик не грузится даже при согласии на cookie. Это правильно: Метрика,
стартующая до согласия, — повод для штрафа до 700 000 ₽.

После подключения проверьте **маскирование полей формы в Вебвизоре**, иначе телефоны
посетителей окажутся в записях сессий.

Код уже отправляет пять целей, их нужно только создать в интерфейсе:
`form_sent`, `call_click`, `whatsapp_click`, `telegram_click`, `messenger_click`.
Без них Директ не сможет оптимизироваться по конверсиям.

## 7. Хостинг

**Выкладывать:** `*.html`, `css/`, `js/`, `img/`, `fonts/`, `vendor/`, `favicon/`,
`robots.txt`, `sitemap.xml`, `site.webmanifest`, `menu-riviera-hall.pdf`, `.htaccess`.

**Не выкладывать:** `_архив/`, `20 версия/`, `21 версия/`, `рефы для дизайна сайта/`,
`РИВЬЕРА ХОЛЛ/`, `.agents/`, `.claude/`, `*.md`, `nginx.conf.example` — всё уже
в `.gitignore`.

Конфигурация: [.htaccess](.htaccess) для Apache работает сразу,
[nginx.conf.example](nginx.conf.example) — образец для администратора.
Там редиректы на https и без www, заголовки безопасности, gzip и кеш.

**Оговорка про HSTS:** директиву `Strict-Transport-Security` включайте только после
того, как сертификат точно работает. У уже зашедших посетителей откатить её нельзя —
браузер год будет отказываться открывать сайт по http.

**Про версии файлов.** CSS и JS подключены с меткой `?v=53`. Меняя `style.css` или
`main.js`, поднимайте номер сразу во всех html — иначе посетители получат старую
версию из кеша:

```bash
grep -rl "?v=53" --include="*.html" . | xargs sed -i 's|?v=53|?v=54|g'
```

## 8. Не на сайте

### Уведомление в Роскомнадзор — начните с этого

[pd.rkn.gov.ru](https://pd.rkn.gov.ru) или Госуслуги, бесплатно, около 20 минут.
**В реестр вносят до 30 календарных дней** — подавайте сейчас, а не в день запуска
рекламы. Обязанность по ст. 22 152-ФЗ, касается всех, у кого на сайте есть форма.
Штраф за неподачу — до 300 000 ₽.

### Юридическая приёмка

`privacy.html` помечена как черновик — пометка видна посетителю. Снимите её после
того, как реквизиты заполнены и юрист посмотрел текст.

### Право на изображение гостей

На фотографиях узнаваемые лица. Авторские права на снимки не заменяют согласие
изображённого человека на обнародование (ст. 152.1 ГК). Внесите в договор аренды
пункт о праве использовать фото- и видеоматериалы мероприятия в рекламе.

### Прочее

- Фиксация согласий: дата, время, IP по каждой заявке.
- Журнал учёта обращений субъектов ПДн.
- Подтвердить права в Яндекс.Вебмастере, отправить `sitemap.xml`.
- Резервное копирование — сейчас единственная копия в Git на вашем компьютере.
- Проверить сайт в Safari на iPhone и Яндекс.Браузере.

## 9. Что осталось на ваше решение

Эти три вещи я нашёл в аудите, но **не менял** — они затрагивают внешний вид
или содержание сайта, а это ваша территория.

### Отзывы

Шесть отзывов на месте и работают. Но площадка ещё не открывалась, а два отзыва
датированы будущим — «сентябрь 2026» и «октябрь 2026» при сегодняшнем августе.
Выдуманные отзывы подпадают под ст. 5 закона «О рекламе»; ответственность
по ст. 14.3 КоАП для юрлиц — до 500 000 ₽ за факт. Риск ваш, решение тоже.

Как минимум я бы поправил даты на прошедшие — сейчас это заметно любому,
кто посмотрит на календарь.

### Видео

В секции «08 — видео» стоит фотография с кнопкой play, за которой ничего
не открывается. Либо снять ролик, либо убрать секцию.

### Строка «Ко мне обратились 1844 пользователей»

Цифра ничем не подтверждается и легко читается как подделанное социальное
доказательство. Плюс ошибка согласования: правильно «1844 пользователя».

### Документы, которых нет

Яндекс Директ при модерации ожидает в подвале реквизиты, политику
конфиденциальности **и пользовательское соглашение**. Соглашения нет.

Я подготовил три черновика — [consent.html](consent.html) (согласие на обработку ПДн
отдельным документом), [terms.html](terms.html) (пользовательское соглашение),
[offer.html](offer.html) (условия бронирования). **Они лежат в папке, но никуда
не подключены** — чтобы не менять подвал без вашего согласия. Если нужны, скажите,
добавлю ссылки. Если нет — удалите три файла и уберите их из `sitemap.xml`.

### Согласия на обработку ПДн под формой нет

Сейчас под формой нет чекбокса согласия. По 152-ФЗ он обязателен: не отмеченный
по умолчанию, отдельным действием, со ссылкой на политику. Это добавляет одну
строку под полями — то есть меняет вид формы, поэтому я не стал делать сам.
Из всего списка это единственное, что я бы настоятельно рекомендовал добавить
до запуска рекламы: штраф за обработку без надлежащего согласия — до 700 000 ₽.
